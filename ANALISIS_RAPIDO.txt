================================================================================
DECISIONES DE DISEÑO
================================================================================

✓ Modelos separados: SurveyPack vs EncuestaModel (no mezclar)
✓ Tablas caché: Datos servidor + copia local para offline
✓ Retry exponencial: En tabla separada para tracking
✓ Autenticación: Email+password para /survey/auth/* (no JWT)
✓ IDs: UUID para packs, INTEGER para respuestas locales
✓ Background sync: WorkManager (cada 15 minutos)
